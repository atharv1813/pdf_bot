agent> ## Human-in-the-Loop (HITL) in LangGraph

**Human-in-the-Loop (HITL)** is a core feature of LangGraph that allows humans to stay in control of AI agent workflows — pausing execution, reviewing decisions, providing input, and approving actions before the agent continues.

---

### 🔑 Why Use HITL?
- **Reliability & Safety** — Prevent agents from taking unintended or dangerous actions.
- **Oversight** — Allow humans to review and approve agent steps at critical moments.
- **Routing** — Escalate complex or ambiguous queries to a human when the agent can't confidently handle them.
- **Long-running workflows** — Keep agents on course by persisting state while waiting for human input.

---

### 🛠️ Core Primitives

| Primitive | Purpose |
|---|---|
| `interrupt(value=...)` | **Pauses** graph execution at a node and waits for human input |
| `Command(resume=...)` | **Resumes** a paused graph with human-provided input |
| `Command(update=..., goto=...)` | Updates state with human input and routes to the next node |
| `InMemorySaver` / Checkpointing | **Saves** graph state during interrupts for seamless resumption |

---

### ⏸️ How It Works — Step by Step

1. **Graph runs** until it hits a node that calls `interrupt()`.
2. **Execution pauses** — the current state is saved via checkpointing.
3. **Human is prompted** for input (e.g., approval, correction, or a message).
4. **Human responds** using `Command(resume=...)`.
5. **Graph resumes** from where it left off with the human's input.

---

### 📝 Code Example

```python
from langgraph.types import Command, interrupt
from langgraph.checkpoint.memory import InMemorySaver

# A node that collects human input
def human_node(state) -> Command:
    user_input = interrupt(value="Ready for user input.")  # ⏸️ Pauses here

    return Command(
        update={
            "messages": [{"role": "human", "content": user_input}]
        },
        goto="agent"  # ▶️ Resumes and routes to the agent
    )

# Resuming the graph after human responds
result = graph.stream(
    Command(resume="Yes, please proceed!"),
    thread_config
)
```

---

### 🔄 Multi-Turn Conversations

For ongoing conversations, repeated `interrupt` + `Command(resume=...)` calls allow stateful, multi-turn human-agent dialogue:

```python
inputs = [
    {"messages": [{"role": "user", "content": "I want to plan a trip."}]},
    Command(resume="I prefer beach destinations."),   # 2nd turn
    Command(resume="Book the first option please."),  # 3rd turn
]
```

---

### 💾 Checkpointing is Essential

HITL relies on **checkpointing** to save graph state when paused. Without it, the graph wouldn't know where to resume. LangGraph provides `InMemorySaver` for simple use cases and supports persistent backends (like databases) for production.

---

### Summary

> **Human-in-the-loop in LangGraph = `interrupt` to pause + `Command` to resume + checkpointing to persist state.**

It's what makes LangGraph suitable for building **safe, controllable, and trustworthy AI agents** where human oversight is critical.

## 📊 Key Observations

- **2000–2002**: The rupee weakened slightly, going from ₹44.94 to a high of ₹48.61, driven by global uncertainty and the dot-com bust.
- **2003–2005**: Gradual stabilization as India's economy picked up momentum with IT exports and foreign investment.
- **2007**: The rupee **strengthened significantly** to ₹41.35, its strongest point in this period, due to strong capital inflows and India's booming economy.
- **2008–2009**: The rupee **weakened again** to ₹48.41 due to the **Global Financial Crisis**, which led to capital outflows and increased oil import costs.
- **2010**: Recovery to ₹45.73 as global markets stabilized.
